GNUSIM8085 REFERENCE

8085 assembly program

Use this as a learning reference in the GNUSim8085 simulator.

student_mark_calculation.asm8085 ASM
; Student Mark Calculation - GNUSim8085
; Input memory: 2050H, 2051H, 2052H
; Output: total at 2053H, quotient at 2055H
; Note: 8-bit total must be 0 to 255.
; Marks are entered as hexadecimal values.

LDA 2050H
MOV B, A
LDA 2051H
ADD B
MOV B, A
LDA 2052H
ADD B
STA 2053H

; Divide total by 3 using repeated subtraction
MVI B, 03H
MVI C, 00H

LOOP: CMP B
JC NEXT
SUB B
INR C
JMP LOOP

NEXT: STA 2054H
MOV A, C
STA 2055H
HLT
i

Important: This simple 8-bit assembly example can store totals only up to 255. For three marks that may add up to 300, use a 16-bit total version or choose inputs whose total is 255 or less. The web calculator supports the full 0–300 range.
